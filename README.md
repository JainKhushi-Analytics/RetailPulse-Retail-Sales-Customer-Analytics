# RetailPulse: Retail Sales & Customer Analytics

## Project Overview
RetailPulse is a Power BI dashboard project designed to analyze retail sales, revenue, profit, product performance, customer behavior, and inventory risks. It helps users explore business performance through interactive visualizations and filters.

## Objectives
- Analyze retail sales and revenue trends.
- Identify top-performing products.
- Understand customer purchasing behavior.
- Compare sales across countries.
- Analyze monthly and seasonal sales patterns.
- Identify potential inventory risks.
- Support data-driven business decisions.

## Tools & Technologies
- Microsoft Power BI
- Power Query for data preparation
- DAX for calculations and measures
- Excel/CSV retail dataset
- GitHub for project documentation and version control
